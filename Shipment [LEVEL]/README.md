
# **Shipment** #
Also known as "BrainRot", is a custom Unreal Tournament 99 level.

This is a rough recreation of shipment map from CoD games.

Map is created in Deathmatch, CTF and Domination variants.

## 📥 Installation

Download and extract `Shipment.rar` into your Unreal Tournament installation directory.

## 📝 Notes
- **Dependencies:** The map uses native textures from `city.utx` and `genfluid.utx`.
